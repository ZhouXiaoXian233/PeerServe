## 3. 安全测试

- 超长字符串（每个字段的上限 + 1）；
- 非法 JSON、重复键、`NaN`/`Infinity`、深度嵌套；
- 超大消息（> 64 KiB）；
- 不支持的 `schema_version`；
- 无效签名 / 空签名 / 截断签名；
- 重放消息与重复 ID；
- 伪造 reviewer（非参与者）；
- 日志中不出现私钥（断言日志输出）；
- 精确坐标不进入广播摘要。

## 4. 人工验收（两台真机）

1. A 发布"从 X 到 Y"的出行需求；
2. B 提交响应；
3. A 选择 B，双方看到同一组条款；
4. 双方签署协议；
5. B 记录开始服务；
6. B 声明完成；
7. A 确认完成；
8. 双方各自评价对方；
9. 第三方设备能区分：协议事实 / 单方声明 / 评价；
10. 断开网络后，双方仍可查看本地记录。

## 6. 报告规则

- CI 与 PR 必须贴**真实命令与真实输出**；
- 失败就是失败，不得写"应该可以通过"；
- 新增测试必须能在干净环境中独立运行（不依赖本机已有数据）。
