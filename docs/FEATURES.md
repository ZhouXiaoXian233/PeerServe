# 功能清单（开发记录）

> 最后更新：2026-11-07 · 以当前代码与测试为准，不是产品承诺。
> 应用内不再展示此清单；页面只保留用户需要的主操作。

## 已完成

- [x] pub workspace 根 `pubspec.yaml` 与单一 lockfile
- [x] 无浮点 JCS 子集（键排序、字符串转义、安全整数）
- [x] 严格 JSON：拒绝重复键、浮点、超长、超深嵌套、孤立代理项
- [x] 签名信封：域分离前缀，签名覆盖 `schema_version` / `type` / `sender_id` / `sent_at` / `payload`
- [x] Ed25519 种子派生、签名、验签
- [x] `did:key`（Ed25519 multicodec + base58btc）编解码
- [x] RFC 8032 TEST 1–3、JCS 用例、固定信封向量、固定 Request 向量
- [x] Request v1：类别、地点、时间窗、价格、过期时间、nonce、逐字段校验
- [x] Request 装入签名信封并可独立验签
- [x] Offer v1：说明、可选报价/时间、有效期、逐字段校验
- [x] 对需求签名响应（Offer）并立即验签，显示“我的响应”
- [x] 不能响应自己的需求；过期需求拒绝；Offer 必须指向本机存在的 Request
- [x] 本机共享会话：身份、资料、需求与响应在页面之间保持一致（仅内存）
- [x] 首页 / 个人中心 / 身份页 / 需求公告板；发布需求表单
- [x] 个人中心：昵称、内置头像、简介、常用起终点（仅本机）
- [x] 启动时放入 4 条“示例”签名需求，明确标记，不冒充真实用户
- [x] 需求列表显示发布者头像、昵称、签名状态与“示例”标记
- [x] 需求类别筛选（全部 / 出行 / 带物 / 餐饮 / 跑腿 / 其他）
- [x] 暖纸主题、渐变 Hero、最近需求预览、个人中心渐变资料头
- [x] 发布失败时在表单内显示错误码与原因
- [x] 开发者详情 / 技术详情只在 `kDebugMode` 显示，release 构建不出现
- [x] 篡改 payload 后验签失败的开发者演示（debug）
- [x] web 宿主仅用于本地预览（非发布目标）

## 部分完成

- [ ] 身份与个人资料持久化：当前只在内存，重启丢失
- [ ] 头像上传：首版只有内置表情头像；图片选择/裁剪需要存储与权限
- [ ] 公告板体验：有列表、类别筛选与发布，无搜索、详情编辑、撤回
- [ ] Offer 管理：能响应，但还不能由需求方比较/选择/接受 Offer
- [ ] 数据来源展示：本机签名状态已有，但无"来自节点 / 最后同步时间"
- [ ] 时间显示：目前使用 UTC 原始时间，未做本地化格式化
